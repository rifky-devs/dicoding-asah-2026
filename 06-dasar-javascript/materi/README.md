# Catatan Materi

Tambahkan satu folder untuk setiap modul yang ingin dicatat. Gunakan judul modul dari Dicoding agar gampang dicari.

Contoh struktur:

```text
materi/
└── 01-judul-modul/
    └── catatan.md
```

Isi catatan dengan ringkasan sendiri, contoh yang sudah dicoba, dan hal yang masih membingungkan. Tidak perlu menyalin seluruh materi course.
