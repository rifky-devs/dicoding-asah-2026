## Cara pakai

- Catatan per modul disimpan di folder `materi/`.
- Latihan atau kode percobaan disimpan di `latihan/`.
- Hal penting yang ingin diingat ditulis di `rangkuman.md`.
- Kalau ada bagian yang belum lancar, catat di `evaluasi-diri.md`.
- Setelah menambah atau mengubah file, simpan perubahan dengan Git.

Folder modul sengaja belum dibuat satu per satu karena nama dan jumlah modul harus mengikuti isi course di Dicoding. Tambahkan foldernya saat mulai mencatat materi.
